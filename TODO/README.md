# Work corpus

This directory is the executable backlog for bit-ids. Start with
[`PROGRESS.md`](PROGRESS.md), use [`INDEX.md`](INDEX.md) to locate an entry,
and apply [`RULES.md`](RULES.md) before changing status. [`ENTRY.md`](ENTRY.md)
is the entry pattern; it is not itself a work item.

Category files:

- [`foundation.md`](foundation.md)
- [`schema.md`](schema.md)
- [`observer.md`](observer.md)
- [`acquisition.md`](acquisition.md)
- [`clients.md`](clients.md)
- [`engines.md`](engines.md)
- [`corpus.md`](corpus.md)
- [`library.md`](library.md)
- [`publishing.md`](publishing.md)
- [`ci.md`](ci.md)
- [`documentation.md`](documentation.md)

[`SUMMARY.md`](SUMMARY.md) is a compact, mechanically checked count table.
The current work order exists only in [`PROGRESS.md`](PROGRESS.md).
