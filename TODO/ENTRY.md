# Entry pattern

Use this field order for a new entry. Replace the lowercase brace tokens and
remove any unused decision paragraph.

```text
## {entry-id}: {outcome title}

Source: {provenance}
Priority: {priority} | Effort: {effort} | Status: {status}

Problem: {observable gap}

Premise: {belief and how it was established}

Approach: {implementation seam and important constraints}

Decision: {choice, alternative, and reason}

Prove: {literal acceptance command and expected result}
```
